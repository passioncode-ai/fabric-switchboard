# Security

Report a vulnerability in Fabric Switchboard privately, never in a public issue:

- GitHub private vulnerability reporting: **Security → Report a vulnerability** on
  [passioncode-ai/fabric-switchboard](https://github.com/passioncode-ai/fabric-switchboard/security/advisories/new), or
- email contact@passioncode.ai.

Do not put a credential, a provider prompt, a raw upstream error body or a working exploit
against someone else's account in the report; describe the path instead. The supported
version is the latest published release.
