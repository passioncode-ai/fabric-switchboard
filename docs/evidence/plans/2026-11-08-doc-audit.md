## Findings, by seam

**F-1. No single decision home** (seam: decision to document).
`docs/PLAN-0.3.md`, `PLAN-0.4.md`, `PLAN-0.5.md` and research notes number their own `D-<n>`;
operator decisions are dated inside board rows, `AGENTS.md` and `CHANGELOG.md`. A decision
reaches the documents it changes only by hand, and pass 3 has nothing to follow.
→ Open `docs/DECISIONS.md` (`DEC-<nnnn>`, append-only, guarded), seed it with the decisions still
in force that the board cites (operator decisions of 2026-10-11 SB-98, 2026-11-04 SB-246, D-1 and
D-2 of 0.6.82), each with a `Consequences / affects:` line.

**F-2. Status words were free text** (seam: register to reader).
A reader takes a status's first word (Fabric `scripts/lib/disposition.mjs` `tokenOf`); 32 closed
rows began with `open`. Fixed for those rows in #528, and the board's header now says a status
starts with its state. → Add a check to `./scripts/check.sh` that the first word of every status
is one of a declared list, and that a status whose last note is a dated `closed` starts with
`closed`.

**F-3. The docs check has no planted-defect test** (seam: gate to evidence).
`scripts/check_docs.py` proves links resolve and scenarios name coverage, and no test plants a
broken link to watch it fail. → Add `scripts/test_check_docs.py` (a temporary tree with a broken
link and a scenario without coverage) to the gate.

**F-4. No scenario linter** (seam: scenario to code).
`docs/ux/lint.py` is absent, so the matrix row for interface behaviour rests on review.
→ `/ux-init` (super-ux), then put the linter into `./scripts/check.sh`.
