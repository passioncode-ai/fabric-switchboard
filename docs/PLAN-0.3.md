# 0.3 — existing CLI accounts, import and quota rotation

Operator request: capture an already authenticated console account without another login; keep official Terminal login for additional accounts; import Claude Swap; identify the actual current CLI account; periodically measure quota windows and rotate when configured limits are reached.

## Shared contracts

- Credential remains vault-only, never Debug/renderer/control output. Optional `native_context: Option<serde_json::Value>` holds a bounded native Claude envelope `{auth, oauth_account}` for faithful activation. Account metadata gains optional `external_identity: ExternalIdentity { account_id: Option<String>, organization_id: Option<String>, email: Option<String> }`. Match provider + pool + account/org; token equality is a fallback only when identity is absent. Reimport updates credential generation without duplicating accounts or enabling disabled rows.
- `Store::upsert(label, provider, kind, pool, credential, external_identity) -> Result<Account,String>`; `Store::stored_credential(id)` permits backend capture/synchronization of expired credentials without making them eligible for requests. `Store::match_external(provider,pool,&identity) -> Result<Option<Account>,String>`.
- Usage retains aggregate fields and adds `windows: Vec<UsageWindow { name:String, used_percent:f64, resets_at:Option<i64> }>` (default empty for old data). Account adds optional `usage_health: UsageHealth { status:String, checked_at:i64, next_check_at:i64 }`. Fixed statuses only: ok, failed, unavailable. Never expose provider error bodies.
- Snapshot adds default `policies: Vec<RotationPolicy>`. Policy: `{provider,pool,target: "managed"|"claude_cli",enabled,threshold_percent,hysteresis_percent,cooldown_seconds,max_age_seconds,last_switched_at:Option<i64>}`. Native target is Claude OAuth only. `Store::set_policy(policy)` validates; `Store::rotation_decision(&policy,current_id,now) -> Result<RotationDecision,String>` returns `{candidate_id:Option<String>,reason:String}`; `Store::mark_rotated(provider,pool,target,now)` records cooldown. Selection needs fresh valid usage, enabled account and nonexpired credential; threshold + hysteresis + cooldown, same pool/provider, no replay; no eligible account means hold. Settings persist, default disabled.
- `Store::usage_health(id,status,checked_at,next_check_at)` persists health without erasing last good usage. Poller uses 180 s normal cadence, bounded work per pass, exponential failure backoff, only authenticated quota endpoints. Source refresh generation can be recaptured from the live CLI, but Switchboard does not run competing OAuth refresh grants.
- Runtime operations: `current_accounts` => `{claude: CurrentAccount,codex: CurrentAccount}` where CurrentAccount `{status: "available"|"missing"|"unavailable",identity:ExternalIdentity|null,account_id:string|null}` (pool default). `capture_current {provider,label?,pool}` => Account. `import_claude_swap {pool}` => `{imported:Account[],failed:number,skipped:number}`. `activate_native {id}` => null. `set_policy {policy}` => null. `monitor_status` => `{running:boolean,interval_seconds:180}`. Existing begin/finish login continue using official console and isolated homes.
- Runtime external module: `capture_current(provider) -> CapturedProfile`, `read_claude_swap() -> ImportBatch`, `activate_claude(&Credential,&ExternalIdentity,expected_current:Option<&ExternalIdentity>) -> Result<(),String>`. `CapturedProfile {provider,kind,credential,identity,label}` and `ImportBatch {profiles:Vec<CapturedProfile>,failed:usize,skipped:usize}` must never Debug/Serialize. Current observation comes from capture without returning secret material. Native activation validates identity, obtains Claude-compatible lock directories, checks current identity after lock acquisition, splices only oauthAccount, writes credential plus rollback, refuses unsafe paths or locks. No process killing, no prompt replay. Current CLI identity and managed route are shown separately.

## Bounded implementation packets

1. Core/proxy: metadata migration, identity upsert, policy evaluation, detailed quota parsing, clock-controlled tests. Own `crates/switchboard-core/**`, `crates/switchboard-proxy/**`.
2. External adapters: read-only current Claude/Codex capture, Claude Swap import, native Claude activation and synthetic file/Keychain tests. Own runtime `external.rs`/`external/**`; coordinate Cargo additions with root. Source pin `realiti4/claude-swap@9aa6d0292736173e70d4c5d8e2026210fe39a9ee`.
3. Interface: capture-first add flow, official-login alternative, import action, actual CLI identity, usage windows/freshness and rotation settings; demo fixtures. Own `src/**`, UX scenario additions.
4. Root: runtime monitor/operations, CLI/Tauri glue, login capture enrichment, integration/review, documentation, version/build/delivery. No agent edits another packet's files.
